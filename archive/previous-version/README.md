## Reason for Archival

During preliminary review, several assumptions regarding attendance capture workflows, student self-confirmation, session tokens, and reporting workflows were noted as unconfirmed or open questions. Development is restarting from a clean baseline to incorporate newly confirmed college requirements without carrying forward legacy assumptions.
