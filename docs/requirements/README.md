## Structure

Once confirmed requirements are provided, the following documents will be maintained here:
- `CONFIRMED_REQUIREMENTS.md` — Raw confirmed inputs and constraints directly from college staff.
- `SRS.md` — Formal Software Requirements Specification defining functional and non-functional requirements.
- `USER_STORIES.md` — Role-based user stories and acceptance criteria (Student, Faculty, HOD, Admin).
