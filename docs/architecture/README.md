# System Architecture

This directory documents the high-level system architecture, service interactions, component topologies, and security boundaries.

---

## Status

- **Current State:** Pending requirements confirmation.
- **Goal:** Establish a modular, maintainable, institutional-grade architecture suited to the college deployment environment.

---

## Areas to Cover

1. **System Context:** High-level interaction between students, faculty, administrators, internal database, and college email relays.
2. **Component Architecture:** Backend service layer, API layer, frontend presentation layer.
3. **Authentication & Authorization:** Institutional RBAC (Role-Based Access Control) model.
4. **Attendance Calculation Pipeline:** Engine for real-time subject-wise and semester-wise calculations, threshold alerts, and compliance flags.
